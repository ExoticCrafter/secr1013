### 🧠 Course Overview
**Digital Logic (SECR1013)** provides a comprehensive introduction to digital electronics, focusing on the fundamental principles of **combinational and sequential logic circuits**.

This repository serves as a personal archive for assignments, lab exercises (Deeds/Logisim), and projects throughout the course.

#### 🧩 Topics Covered:
- Number Systems & Codes
- Logic Gates
- Boolean Algebra
- Karnaugh Maps (K-Map) simplification
- Latches & Flip-Flops
- Counters & Registers
